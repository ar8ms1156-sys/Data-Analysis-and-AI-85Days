# 🛒 مشروع تحليل بيانات التجارة الإلكترونية السعودية (Saudi E-Commerce Analytics)
> **إستراتيجيات نمو المبيعات وتحليل سلوك المستهلك باستعمال T-SQL ووسائل العرض البياني**

---

## 📌 1. الملخص التنفيذي (Executive Summary)

يقدم هذا المشروع تحليلاً شاملاً لبيانات متجر إلكتروني سعودي عبر قاعدة البيانات **`Saudi_Ecommerce_DB`**، بهدف تقديم رؤى تجارية استراتيجية (Business Insights) تدعم اتخاذ القرار وتزيد من كفاءة العمليات التشغيلية واللوجستية وفق متطلبات سوق التجارة الإلكترونية الواعد في المملكة العربية السعودية.

تم الاعتماد على لغة **T-SQL** لبناء استعلامات مخصصة تقوم على تقييم 4 محاور تحليلية رئيسية: **التوزيع الجغرافي للمبيعات، شرائح حجم السلة الشرائية، سلوك كبار العملاء (VIP)، ومقارنة متوسط الإنفاق حسب المناطق بالمتوسط العام للمتجر**.

---

## 🗄️ 2. معمارية وهيكلية البيانات (Database Schema)

تتكون قاعدة البيانات Relational Database من جدولين رئيسيين مع ربط كامل لسلامة البيانات (Referential Integrity):

* **جدول العملاء `Customers`:** يتضمن البيانات الديموغرافية (معرف العميل `CustomerID` كـ Primary Key، الاسم، المدينة، والجنس).
* **جدول الطلبات `Orders`:** يتضمن تفاصيل المعاملات المالية (معرف الطلب `OrderID` كـ Primary Key، المفتاح الأجنبي `CustomerID` كـ Foreign Key، تاريخ الطلب، القيمة الإجمالية `TotalAmountSAR` بالريال السعودي، وفئة المنتج).

## 📊 3. المحرك التحليلي ولوحات القيادة (Analytical Engine & Results)

### 🗺️ المحور الأول: أكثر 5 مدن سعودية توليداً للإيرادات

يهدف هذا الاستعلام إلى كشف المراكز الحضرية الرائدة في قيادة المبيعات لتوجيه التركيز اللوجستي والتسويقي.

![تقرير المبيعات الإقليمي](./Pictures/picture1.png)

```sql
-- استعلام أكثر 5 مدن توليداً للمبيعات وإجمالي الإيرادات
SELECT TOP 5 
    c.City AS [المدينة],
    COUNT(o.OrderID) AS [عدد الطلبات],
    CONCAT(SUM(o.TotalAmountSAR), ' SAR') AS [إجمالي المبيعات]
FROM Customers c
INNER JOIN Orders o ON c.CustomerID = o.CustomerID
GROUP BY c.City
ORDER BY SUM(o.TotalAmountSAR) DESC;
```

| الترتيب | المدينة | عدد الطلبات | إجمالي الإيرادات (SAR) |
| :---: | :--- | :---: | :---: |
| **1** | الرياض | 20 | 23,710.00 SAR |
| **2** | جدة | 16 | 18,155.00 SAR |
| **3** | مكة المكرمة | 5 | 12,240.00 SAR |
| **4** | أبها | 8 | 11,870.00 SAR |
| **5** | المدينة المنورة | 7 | 9,550.00 SAR |

> **💡 إضاءة تحليلية استراتيجية:** تستحوذ العاصمة **الرياض** وتليها **جدة** على الكتلة الحيوية للمبيعات بحجم 36 طلب وإيرادات تتجاوز 41,800 ريال. كما تُظهر مدينة **مكة المكرمة** قوة شرائية عالية جداً بالنظر إلى تحقيقها إيرادات مرتفعة (12,240 ريال) من خلال 5 طلبات فقط، مما يشير إلى ارتفاع متوسط قيمة الطلب الفردي فيها.

### 📦 المحور الثاني: توزيع شرائح حجم السلة الشرائية (Order Value Segmentation)

تصنيف الطلبات إلى فئات تجميعية لمعرفة هيكل الإيرادات ومحركات الإنفاق.

![توزيع حجم السلة الشرائية](./Pictures/picture2.png)

```sql
-- تقرير تجميعي لتوزيع حجم السلة الشرائية
SELECT 
    CASE 
        WHEN o.TotalAmountSAR >= 2500 THEN 'طلب كبير (High Value)'
        WHEN o.TotalAmountSAR >= 1000 THEN 'طلب متوسط (Mid Value)'
        ELSE 'طلب صغير (Low Value)'
    END AS [فئة الطلب],
    COUNT(o.OrderID) AS [عدد الطلبات],
    CONCAT(SUM(o.TotalAmountSAR), ' SAR') AS [إجمالي مبيعات الفئة]
FROM Orders o
GROUP BY 
    CASE 
        WHEN o.TotalAmountSAR >= 2500 THEN 'طلب كبير (High Value)'
        WHEN o.TotalAmountSAR >= 1000 THEN 'طلب متوسط (Mid Value)'
        ELSE 'طلب صغير (Low Value)'
    END
ORDER BY SUM(o.TotalAmountSAR) DESC;
```

| فئة الطلب | عدد الطلبات | إجمالي مبيعات الفئة (SAR) |
| :--- | :---: | :---: |
| **طلب كبير (High Value >= 2500)** | 17 | 62,450.00 SAR |
| **طلب صغير (Low Value < 1000)** | 62 | 32,950.00 SAR |
| **طلب متوسط (Mid Value 1000-2499)** | 21 | 31,880.00 SAR |

> **💡 إضاءة تحليلية استراتيجية:** تُمثل شريحة "الطلبات الكبيرة" المحرك الأساسي لإيرادات المتجر برصيد 62,450 ريال (تتجاوز 49% من إجمالي مبيعات المتجر) من خلال 17 طلباً فقط. في المقابل، تشكل "الطلبات الصغيرة" 62% من حجم الطلبات الكلي (62 طلباً)، مما يبرز فرصة استراتيجية لرفع قيمتها عبر آليات التجميع (Cross-selling / Bundling).

### 👑 المحور الثالث: تحليل سلوك وتوزيع كبار العملاء (VIP Customers)

تحديد كبار المستهلكين الذين تجاوز إنفاقهم الفردي حاجز 4,000 ريال سعودي لبناء برامج ولاء مخصصة.

![كبار العملاء VIP](./Pictures/picture3.png)

```sql
-- تحديد العملاء الذين تجاوزت مشترياتهم 4000 ريال (VIP Customers)
SELECT 
    c.CustomerID AS [رقم العميل],
    c.CustomerName AS [اسم العميل],
    c.City AS [المدينة],
    CONCAT(o.TotalAmountSAR, ' SAR') AS [إجمالي المشتريات]
FROM Customers c
INNER JOIN Orders o ON c.CustomerID = o.CustomerID
WHERE o.TotalAmountSAR >= 4000
ORDER BY o.TotalAmountSAR DESC;
```

| **4** | نهى النميمي | حائل | 4,500.00 SAR |
| **5** | بادر السبيعي | القصيم | 4,200.00 SAR |

> **💡 إضاءة تحليلية استراتيجية:** تتركز نخبة كبار العملاء في مدن جدة ومكة المكرمة والقصيم وحائل. استهداف هذه الشريحة يضمن الحفاظ على معدل Retention مرتفع ويزيد من القيمة الكلية للعميل (Customer Lifetime Value - CLV).

### 📈 المحور الرابع: مقارنة متوسط السلة الشرائية الإقليمية بالمتوسط العام للمتجر

تحليل متوسط قيمة الطلب (AOV) لكل مدينة ومقارنته بالمتوسط العام الإجمالي للمتجر البالغ **1,327.08 SAR**.

![تحليل متوسط المبيعات لكل مدينة](./Pictures/picture4.png)

```sql
-- تحليل متوسط قيمة المبيعات لكل مدينة ومقارنتها بالمتوسط العام لمبيعات المتجر باستعمال Subquery
SELECT 
    c.City AS [المدينة],
    COUNT(o.OrderID) AS [عدد الطلبات],
    CONCAT(CAST(AVG(o.TotalAmountSAR) AS DECIMAL(10,2)), ' SAR') AS [متوسط قيمة الطلب],
    CONCAT(SUM(o.TotalAmountSAR), ' SAR') AS [إجمالي المبيعات]
FROM Customers c
INNER JOIN Orders o ON c.CustomerID = o.CustomerID
GROUP BY c.City
HAVING AVG(o.TotalAmountSAR) > (SELECT AVG(TotalAmountSAR) FROM Orders)
ORDER BY AVG(o.TotalAmountSAR) DESC;
```

| المدينة | عدد الطلبات | متوسط قيمة الطلب (AOV) | إجمالي المبيعات (SAR) |
| :--- | :---: | :---: | :---: |
| **الباحة** | 1 | 3,600.00 SAR | 3,600.00 SAR |
| **مكة المكرمة** | 5 | 2,448.00 SAR | 12,240.00 SAR |
| **حفر الباطن** | 1 | 2,200.00 SAR | 2,200.00 SAR |
| **الطائف** | 5 | 1,818.00 SAR | 9,090.00 SAR |
| **حائل** | 6 | 1,532.50 SAR | 9,195.00 SAR |
| **أبها** | 8 | 1,483.75 SAR | 11,870.00 SAR |
| **المدينة المنورة** | 7 | 1,364.29 SAR | 9,550.00 SAR |

> **💡 إضاءة تحليلية استراتيجية:** تتفوق 7 مدن على المتوسط العام للمتجر (1,327.08 SAR)، وتتصدر **الباحة ومكة المكرمة وحفر الباطن** القائمة بأعلى متوسط سلة شرائية، مما يشير إلى وجود استهلاك مرتفع للمنتجات الفاخرة أو ذات القيمة المالية العالية في هذه المناطق.

## 🚀 4. التوصيات الاستراتيجية للأعمال (Strategic Business Recommendations)

1. **التوسع والتكامل اللوجستي الإقليمي:**
   * إنشاء مراكز تجميع واستيفاء طلبات (Fulfillment Hubs) مصغرة في **الرياض وجدة** لتقليل تكلفة وسرعة الشحن، بالنظر إلى استحواذهما على النسبة الأكبر من حجم المعاملات.
2. **برامج الولاء الخاصة بشريحة الـ VIP:**
   * إطلاق برنامج **VIP Privileges** مخصص للعملاء في مدن (جدة، مكة، حائل، والقصيم) يقدم خدمات التوصيل السريع مجاناً والدعم الأولي لتشجيع تكرار عمليات الشراء.
3. **تحسين متوسط قيمة السلة (AOV Maximization):**
   * تفعيل استراتيجيات التوصية الذكية للمنتجات (Cross-Selling) وحزم المنتجات (Bundling) لشريحة "الطلبات الصغيرة" (<1000 ريال) لدفعها نحو شريحة الطلبات المتوسطة وتجاوز حاجز 1,327 ريال.
4. **حملات تسويقية جغرافية موجهة (Geo-Targeted Marketing):**
   * تركيز الحملات الترويجية للمنتجات عالية القيمة في مدن **مكة المكرمة والتراكمات الحضرية الواعدة كالباحة وحفر الباطن** للاستفادة من قدرة المستهلك العالية على الإنفاق.
